========================================================================
                      FLOW - 개인 가계부 프로그램
========================================================================

FLOW는 직관적인 UI와 강력한 수식 계산 엔진을 탑재한 개인 가계부 응용 프로그램입니다.

[ 주요 특징 및 기능 ]
1. 편리한 가계부 관리: 일별/월별 수입, 지출 및 카테고리별 자산 관리
2. 자동 설치 마법사: Flow_Setup_v1.5.exe 실행 시 바탕화면 및 시작메뉴 자동 등록
3. 안전한 데이터 유지: 프로그램 업데이트 또는 재설치 시에도 기존 DB 내용 보호
4. 자동 업데이트 지원: 런처(launcher.exe)를 통한 최신 안정(stable) 버전 자동 업데이트

[ 실행 및 설치 방법 ]
- Flow_Setup_v1.5.exe 파일 실행 ➔ 안내에 따라 설치 진행 후 바탕화면 바로가기로 실행

[ 구성 파일 ]
- Flow_Setup_v1.5.exe : NSIS 기반 자동 설치 마법사
- Flow_Release.zip   : 무설치 포터블 패키지
- Flow_Setup.nsi     : NSIS 설치 스크립트
- version.json       : 버전 정보 파일
- README.txt         : 안내 문서
